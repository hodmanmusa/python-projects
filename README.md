## Getting started

Clone the repository:

```bash
git clone https://github.com/hodmanmusa/python-projects.git
cd python-projects
```

Create an optional virtual environment:

```bash
python -m venv .venv
```

Activate it in Git Bash on Windows:

```bash
source .venv/Scripts/activate
```

On Linux or macOS:

```bash
source .venv/bin/activate
```

For the Pandas project, install Pandas if needed:

```bash
python -m pip install pandas
```

Open the relevant project directory and inspect its source files and any project-specific dependency or usage instructions before running it. Each project is organized separately; additional dependencies may vary by project.
